# Pixel Drift — data terms

By playing Pixel Drift on this server you agree that:

- **Complete and partial laps** from signed-in accounts may be uploaded to a
  private Hugging Face dataset operated by the project owner, along with the
  account username, car/power choice, input device and gameplay telemetry.
  Partial and reset episodes are labelled as such. Guest sessions stay in the
  player's browser.
- The data is used for leaderboards, analytics and training game AI models.
  It is not sold, published, or shared outside the private dataset.
- Passwords are never included. The only account data is the username.
- After an episode is accepted by the server and committed to the dataset, the
  raw copy is deleted from the game machine and the player's browser to save
  storage.
- To request deletion of your laps, contact the server owner. The admin panel
  can remove a player's leaderboard time and associated lap history.

This is a plain-language notice, not legal advice. Update it with your own
contact details and jurisdiction before treating it as a formal agreement.
